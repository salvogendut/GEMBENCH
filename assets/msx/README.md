# MSX distribution assets

`MSXDOS2.BIN` is the canonical 512-byte MSX-DOS 2 boot sector generated by
openMSX 21's `diskmanipulator create ... 720` command. The floppy builder keeps
the FAT12 BPB produced by `mkfs.fat` at bytes 11 through 29, and installs the
MSX jump/OEM bytes 0 through 10 plus bytes 30 through 511 from this template.

The boot code originates from MSX-DOS/Nextor and is distributed under the
[Nextor license](../../docs/licenses/NEXTOR.md). GEOBENCH does not modify it.

The default wallpaper is the canonical `assets/pictures/LOGO.PIC`, generated
from the GEOBENCH lollipop identity and staged without an MSX-only override.
